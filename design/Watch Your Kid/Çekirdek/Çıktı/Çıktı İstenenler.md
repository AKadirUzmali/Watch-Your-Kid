+ İstenenler:
	+ Çıktı türünün olması
	+ Oluşturulan çıktı nesnesine özel isim verilmesi
	+ Çıktının yazma işlemlerini gerçekleştirebilmesi

	+ Çıktı türünün olması:
		+ Konsol ekranı çıktısı
		+ Dosya çıktısı
		+ Gui çıktısı

	+ Oluşturulan çıktı nesnesine özel isim verilmesi:
		+ Özel isim ile daha okunabilir kılmak:
			+ (get) name
			+ (set) name

	+ Çıktının yazma işlemlerini gerçekleştirebilmesi:
		+ Başlık verilmesini sağlamak
		+ Metin girilmesini sağlamak
		+ Çıktı durum seviyesini bildirmek (hata, başarı, uyarı, bilgi, test vs.)
